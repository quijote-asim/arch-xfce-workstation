#+title: Arch Xfce Workstation

* Objetivo

Documentar un procedimiento reproducible para instalar y configurar una
workstation Arch Linux con Xfce.

Arquitectura principal:

→ UEFI + systemd-boot.
→ Btrfs para la raíz.
→ Snapper para snapshots.
→ /home independiente en XFS.
→ ZRAM para swap ordinaria.
→ Swap física para hibernación.
→ Xfce + LightDM.
→ Configuración orientada al teclado.
